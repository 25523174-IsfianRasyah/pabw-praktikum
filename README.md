### Token yang saya terapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #87919E | tombol, tautan, penanda |
| --color-fg | #554640 | warna teks utama |
| --color-bg | #CDE6F5 | latar halaman |
| --radius-md | 0.5rem | sudut tombol dan kartu |
| --space-4 | 1rem | jarak standar antar elemen |

Kriteria selesai saya: mengubah --color-primary di satu baris
harus mengubah warna tombol, tautan, judul, dan garis fokus.
